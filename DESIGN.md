# Portfolio design brief

Build a personal home on the web for Anay Pandit, a student exploring AI, robotics, and aerospace. This is a lasting personal portfolio, with the Academy application as one possible use.

## Instructions for future AI edits

- Preserve the dark aerospace aesthetic: charcoal #0c1013, off-white #edf1f2, muted blue-gray #a0adb5, and cyan #a2dfd7.
- Follow a proven portfolio structure: a concise introduction, selected work linking to substantive project stories, an About section, selected recognition, and a clear next step.
- Use strong typography, generous whitespace, a readable content width, consistent spacing, and restrained thin borders. System sans-serif is for reading; monospace is for small labels.
- Prefer real photographs, actual app screenshots, and useful engineering drawings. Label illustrations as illustrations. Do not invent product screens, users, outcomes, or testimonials.
- Keep the homepage concise. Each case study should explain the question, personal contribution, build method, evidence, current limitations, and next step.
- Credit team contributions and AI assistance accurately. Keep awards attached to the correct team and date.
- Avoid excessive glow, fake telemetry, decorative dashboards, autoplay media, constant motion, and extra features unrelated to exploring Anay's work.
- Preserve mobile readability, keyboard navigation, semantic HTML, visible focus, meaningful image alt text, and reduced-motion support.
- Use shared CSS and minimal JavaScript. All reading and navigation must work without JavaScript.

## Refinement process

1. Establish content and visual hierarchy before adding decoration.
2. Review actual desktop and phone screenshots.
3. Shorten repeated copy and correct crowded spacing or awkward wrapping.
4. Check every link, image, and interactive demo.
5. Make another pass only for observed defects or requested changes.

This site is a custom implementation, not a copied third-party template. Its structure borrows familiar portfolio conventions; its visual system and content are tailored to Anay.
